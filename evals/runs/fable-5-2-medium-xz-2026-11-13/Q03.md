# Decompression path in XZ Utils: input bytes to output (commit 7baf6835)

Short version: the `xz` tool reads the file into a buffer and calls `lzma_code()` in a loop. Inside liblzma the bytes go through nested decoders: **Stream decoder -> Block decoder -> filter chain (optional Delta/BCJ filters, then LZMA2) -> LZ dictionary -> LZMA range decoder**. Decoded bytes are copied from the dictionary to the output buffer, any BCJ/Delta filters undo their transform, the Block decoder updates the integrity check, and the tool writes the buffer to the output file.

Every liblzma layer is a `lzma_next_coder` with a `code()` function pointer, and each layer calls the `code()` of the layer below it. Each layer is a resumable state machine (a `sequence` enum), so it can stop when input runs out or output is full and continue on the next call.

## 1. The `xz` command-line tool (`src/xz/`)

1. `main()` in `src/xz/main.c` calls `io_init()`, `args_parse()`, then runs `coder_run()` per file (`list_file()` is used instead for `--list`).
2. `coder_run()` (`src/xz/coder.c`):
   - `io_open_src()` opens the input.
   - Reads the first chunk with `io_read(pair, &in_buf, IO_BUFFER_SIZE)` into `in_buf`; `strm.next_in` points at it. This first chunk is needed for format detection.
   - Calls `coder_init()`, then `io_open_dest()` (skipped in `MODE_TEST`), then `coder_normal()` (or `coder_passthru()`), then `io_close()`.
3. `coder_init()`, decompression branch:
   - Flags: `LZMA_IGNORE_CHECK` if `--ignore-check`, else `LZMA_TELL_UNSUPPORTED_CHECK`; `LZMA_CONCATENATED` unless `--single-stream` (which sets `allow_trailing_input`).
   - Format detection on the first chunk: `is_format_xz()` (6 magic bytes `FD 37 7A 58 5A 00`), `is_format_lzip()` (magic `LZIP`), `is_format_lzma()` (13-byte header heuristics, no magic).
   - Decoder creation by format:
     - `FORMAT_XZ`: `lzma_stream_decoder_mt()` when built with `MYTHREAD_ENABLED` (with `memlimit_threading = 0` if one thread, which forces single-threaded behaviour), otherwise `lzma_stream_decoder()`.
     - `FORMAT_LZMA`: `lzma_alone_decoder()`.
     - `FORMAT_LZIP`: `lzma_lzip_decoder()`.
     - `FORMAT_RAW`: `lzma_raw_decoder(&strm, active_filters)`.
     - Unknown format: `CODER_INIT_PASSTHRU` only with `--decompress --stdout --force`; otherwise `LZMA_FORMAT_ERROR`.
   - For non-raw formats it then calls `lzma_code(&strm, LZMA_RUN)` with `next_out = NULL, avail_out = 0` to decode the headers early. This catches a too-low memory limit on the first Block and prints the `LZMA_UNSUPPORTED_CHECK` warning before the output file is opened.
4. `coder_normal()` main loop:
   - Sets `strm.next_out = out_buf.u8`, `avail_out = IO_BUFFER_SIZE`.
   - When `strm.avail_in == 0` and action is `LZMA_RUN`: refill with `io_read()`; when `pair->src_eof` is set, action becomes `LZMA_FINISH` (the decoder needs it with `LZMA_CONCATENATED`).
   - `lzma_code(&strm, action)`.
   - When `strm.avail_out == 0`: `coder_write_output()` -> `io_write()` (no write in `MODE_TEST`), then the output buffer is reset.
   - On any non-`LZMA_OK` result other than `LZMA_UNSUPPORTED_CHECK` it writes out the remaining bytes first (so damaged files still give as much data as possible). On `LZMA_STREAM_END` it succeeds; if trailing input is not allowed it tries to read one more byte, and extra data gives `LZMA_DATA_ERROR`.

`src/xzdec/xzdec.c` is a smaller tool doing the same loop with `fread`/`lzma_code`/`fwrite` and `lzma_stream_decoder(strm, UINT64_MAX, LZMA_CONCATENATED)` (or `lzma_alone_decoder` for lzmadec).

## 2. `lzma_code()` — the API entry (`src/liblzma/common/common.c`)

- Sanity checks (NULL pointers, supported action, reserved fields).
- Tracks the action state `strm->internal->sequence`: `ISEQ_RUN`, `ISEQ_SYNC_FLUSH`, `ISEQ_FULL_FLUSH`, `ISEQ_FINISH`, `ISEQ_FULL_BARRIER`, `ISEQ_END`, `ISEQ_ERROR`.
- Calls `strm->internal->next.code(...)` (the top decoder) with local `in_pos`/`out_pos`, then advances `next_in/avail_in/total_in` and `next_out/avail_out/total_out`.
- Result handling: two calls in a row with no progress give `LZMA_BUF_ERROR` (`allow_buf_error`); `LZMA_STREAM_END` moves to `ISEQ_END`; `LZMA_NO_CHECK`, `LZMA_UNSUPPORTED_CHECK`, `LZMA_GET_CHECK`, `LZMA_MEMLIMIT_ERROR` are not fatal; everything else sets `ISEQ_ERROR`.

## 3. Stream decoder — the `.xz` container (`src/liblzma/common/stream_decoder.c`)

`lzma_stream_decoder()` -> `lzma_stream_decoder_init()` sets `next->code = &stream_decode` and calls `stream_decoder_reset()` (creates the `lzma_index_hash`, sets `SEQ_STREAM_HEADER`). States of `stream_decode()`:

1. `SEQ_STREAM_HEADER`: copies `LZMA_STREAM_HEADER_SIZE` (12) bytes into `coder->buffer` with `lzma_bufcpy()`, then `lzma_stream_header_decode()` (`stream_flags_decoder.c`: magic check -> `LZMA_FORMAT_ERROR`, CRC32 -> `LZMA_DATA_ERROR`, unsupported flags -> `LZMA_OPTIONS_ERROR`). The check type is copied to `block_options.check`. May return `LZMA_NO_CHECK`, `LZMA_UNSUPPORTED_CHECK` or `LZMA_GET_CHECK` depending on flags. For a later concatenated stream a bad magic becomes `LZMA_DATA_ERROR` (`first_stream`).
2. `SEQ_BLOCK_HEADER`: looks at the first byte. If it equals `INDEX_INDICATOR` (0) -> `SEQ_INDEX`. Otherwise `lzma_block_header_size_decode()` gives the header size and the header is copied into `coder->buffer` (max `LZMA_BLOCK_HEADER_SIZE_MAX` = 1024).
3. `SEQ_BLOCK_INIT`: `lzma_block_header_decode()` (CRC32 check, sizes, filter list with up to `LZMA_FILTERS_MAX` = 4 filters; filter properties decoded through `lzma_properties_decode()`/`props_decode`). Then `lzma_raw_decoder_memusage(filters)`: `UINT64_MAX` -> `LZMA_OPTIONS_ERROR`; above `memlimit` -> `LZMA_MEMLIMIT_ERROR` (this state exists separately so the caller can raise the limit and retry); else `lzma_block_decoder_init()`. Filter options are freed with `lzma_filters_free()`.
4. `SEQ_BLOCK_RUN`: calls `block_decoder.code()`. On `LZMA_STREAM_END` it records the Block with `lzma_index_hash_append(unpadded_size, uncompressed_size)` and goes back to `SEQ_BLOCK_HEADER`.
5. `SEQ_INDEX`: `lzma_index_hash_decode()` reads the Index and compares it with the hash built from the Blocks actually decoded.
6. `SEQ_STREAM_FOOTER`: 12 bytes, `lzma_stream_footer_decode()`; `lzma_index_hash_size()` must equal `backward_size`, and `lzma_stream_flags_compare()` must match header vs footer; mismatch -> `LZMA_DATA_ERROR`. Without `LZMA_CONCATENATED` returns `LZMA_STREAM_END`.
7. `SEQ_STREAM_PADDING` (concatenated only): skips zero bytes, which must come in multiples of four; a non-zero byte starts a new Stream via `stream_decoder_reset()`; `LZMA_STREAM_END` only when input ends with `LZMA_FINISH`.

### Multi-threaded variant (`src/liblzma/common/stream_decoder_mt.c`)

`lzma_stream_decoder_mt()` uses `stream_decode_mt()` with the same outer stages but more states: `SEQ_STREAM_HEADER`, `SEQ_BLOCK_HEADER`, `SEQ_BLOCK_INIT`, `SEQ_BLOCK_THR_INIT`, `SEQ_BLOCK_THR_RUN`, `SEQ_BLOCK_DIRECT_INIT`, `SEQ_BLOCK_DIRECT_RUN`, `SEQ_INDEX_WAIT_OUTPUT`, `SEQ_INDEX_DECODE`, `SEQ_STREAM_FOOTER`, `SEQ_STREAM_PADDING`, `SEQ_ERROR`.

- In `SEQ_BLOCK_INIT` it picks **direct mode** (single-threaded, same thread) when `is_direct_mode_needed()` is true for the compressed or uncompressed size (size is `LZMA_VLI_UNKNOWN` or `> SIZE_MAX / 3`), or when the Block's memory need exceeds `memlimit_threading`. Otherwise **threaded mode**, which needs both sizes in the Block Header.
- Threaded mode: `get_thread()`/`initialize_new_thread()` give a worker, an output buffer comes from the output queue (`lzma_outq_prealloc_buf()`, `lzma_outq_get_buf()`), and `lzma_block_decoder_init()` is called for that worker. The main thread copies the Block's compressed bytes into `thr->in`; `worker_decoder()` calls `thr->block_decoder.code()` in chunks of at most 16384 input bytes into `thr->outbuf`. Worker states: `THR_IDLE`, `THR_RUN`, `THR_STOP`, `THR_EXIT`. Partial-output states: `PARTIAL_DISABLED`, `PARTIAL_START`, `PARTIAL_ENABLED`.
- `read_output_and_wait()` hands finished (or partial) output to the caller in Block order with `lzma_outq_read()`. A worker error is stored in `coder->thread_error`.
- `SEQ_INDEX_WAIT_OUTPUT` waits for all queued output before the Index is decoded.

## 4. Block decoder (`src/liblzma/common/block_decoder.c`)

`lzma_block_decoder_init()` sets the limits (`compressed_limit`, `uncompressed_limit`; unknown sizes become maximums based on `LZMA_VLI_MAX`), calls `lzma_check_init()`, and builds the filter chain with `lzma_raw_decoder_init(&coder->next, allocator, block->filters)`. States of `block_decode()`:

1. `SEQ_CODE`: calls the filter chain `coder->next.code()` with input and output clamped to those limits. Adds the used amounts to `compressed_size`/`uncompressed_size`. If the chain returns `LZMA_OK` although the header sizes are already reached -> `LZMA_DATA_ERROR`. New output is fed to `lzma_check_update()` (skipped with `ignore_check`). At `LZMA_STREAM_END` the sizes are compared with the header (`is_size_valid()`) and written back into `coder->block`.
2. `SEQ_PADDING`: Block Padding up to a multiple of 4 bytes; each byte must be `0x00`, else `LZMA_DATA_ERROR`. With `LZMA_CHECK_NONE` returns `LZMA_STREAM_END` here; otherwise `lzma_check_finish()`.
3. `SEQ_CHECK`: reads `lzma_check_size()` bytes into `block->raw_check` and `memcmp`s with the computed value -> `LZMA_DATA_ERROR` on mismatch. The compare is skipped when `ignore_check` is set or the check type is not supported (`lzma_check_is_supported()`).

Check implementations (CRC32, CRC64, SHA-256) are in `src/liblzma/check/`.

## 5. Filter chain setup (`filter_decoder.c`, `filter_common.c`)

- `lzma_raw_decoder_init()` -> `lzma_raw_coder_init(..., &coder_find, false)`.
- `lzma_validate_chain()`: 1 to 4 filters, the last one must be allowed as last (`last_ok`), non-last ones must be `non_last_ok`, at most 3 size-changing filters; else `LZMA_OPTIONS_ERROR`.
- The `decoders[]` table maps Filter IDs to init functions: `LZMA_FILTER_LZMA1` / `LZMA_FILTER_LZMA1EXT` (`lzma_lzma_decoder_init`), `LZMA_FILTER_LZMA2` (`lzma_lzma2_decoder_init`), BCJ filters X86, POWERPC, IA64, ARM, ARMTHUMB, ARM64, SPARC, RISCV (`lzma_simple_*_decoder_init`), and `LZMA_FILTER_DELTA` (`lzma_delta_decoder_init`). Each entry is under its own `HAVE_DECODER_*` ifdef.
- For decoding the filter order is kept as stored (the encoder reverses it). So `filters[0]` is the outermost coder, the one whose output is the final data, and the last filter (LZMA2) is the one that reads the raw compressed bytes. Each filter pulls its input by calling `next.code()`.

Example chain x86 BCJ + LZMA2: Block decoder calls `simple_code()` (x86), which calls `lz_decode()` (LZMA2).

## 6. LZ layer: the dictionary (`src/liblzma/lz/lz_decoder.c`)

`lzma_lz_decoder_init()` sets `next->code = &lz_decode`, calls the format-specific `lz_init` (for LZMA2: `lzma2_decoder_init`), and allocates the dictionary: size raised to at least 4096, rounded up to a multiple of 16, plus `2 * LZ_DICT_REPEAT_MAX` (`LZ_DICT_REPEAT_MAX` = 288). An optional preset dictionary is copied in.

- `lz_decode()`: if this is the last filter (`coder->next.code == NULL`) it calls `decode_buffer()` directly on the input. Otherwise it first fills `coder->temp.buffer` (`LZMA_BUFFER_SIZE` = 4096) from the next filter and decodes from that; flags `next_finished` / `this_finished` track the end.
- `decode_buffer()` loop:
  1. If `dict.pos == dict.size`, wrap: `dict.pos = LZ_DICT_REPEAT_MAX`, `has_wrapped = true`, last `LZ_DICT_REPEAT_MAX` bytes copied to the start.
  2. Set `dict.limit` = position + min(free output space, space left in dictionary).
  3. Call `coder->lz.code()` (LZMA2 or LZMA1), which writes decoded bytes **into the dictionary**.
  4. `memcpy` the new bytes from `dict.buf + dict_start` to `out`. This is the point where uncompressed bytes first reach an output buffer.
  5. If `dict.need_reset`, call `lz_decoder_reset()`. Return on error, on full output, or when the dictionary is not full.

## 7. LZMA2 chunk layer (`src/liblzma/lzma/lzma2_decoder.c`)

`lzma2_decode()` parses the LZMA2 chunk framing. States: `SEQ_CONTROL`, `SEQ_UNCOMPRESSED_1`, `SEQ_UNCOMPRESSED_2`, `SEQ_COMPRESSED_0`, `SEQ_COMPRESSED_1`, `SEQ_PROPERTIES`, `SEQ_LZMA`, `SEQ_COPY`.

- `SEQ_CONTROL` reads the control byte:
  - `0x00`: end marker -> `LZMA_STREAM_END`.
  - `>= 0xE0` or `== 1`: dictionary reset (`dict_reset()`), and new properties are then required.
  - `>= 0x80`: LZMA chunk. Low 5 bits are the top bits of the uncompressed size. `>= 0xC0`: new properties follow (`SEQ_PROPERTIES`). `>= 0xA0`: state reset via `coder->lzma.reset()`.
  - `1` or `2`: uncompressed chunk (`SEQ_COPY`). Values `> 2` below `0x80` -> `LZMA_DATA_ERROR`.
  - A chunk that needs a dictionary reset or properties and does not give them -> `LZMA_DATA_ERROR`.
- Size fields: 2 more bytes of uncompressed size (+1), 2 bytes of compressed size (+1). `lzma.set_uncompressed()` passes the chunk's uncompressed size to the LZMA decoder.
- `SEQ_PROPERTIES`: `lzma_lzma_lclppb_decode()` for lc/lp/pb, then `lzma.reset()`.
- `SEQ_LZMA`: calls the LZMA decoder `coder->lzma.code()`; input used is subtracted from `compressed_size`; using more than the chunk has, or finishing with bytes left, -> `LZMA_DATA_ERROR`.
- `SEQ_COPY`: `dict_write()` copies raw bytes straight into the dictionary.

The dictionary size comes from the Block Header via `lzma_lzma2_props_decode()` (1 byte, value `<= 40`; 40 means `UINT32_MAX`).

## 8. LZMA decoder: range decoding (`src/liblzma/lzma/lzma_decoder.c`)

`lzma_decode()` is the innermost stage. It turns range-coded bits into literals and matches.

- `rc_read_init()` initialises the range decoder from the first bytes of the chunk.
- Local copies of the state: `state`, `rep0`..`rep3`, `pos_mask`, `literal_mask`, `literal_context_bits`, probability arrays.
- Two modes: a fast non-resumable mode used when enough input is guaranteed (`LZMA_IN_REQUIRED` = 20 bytes; not compiled with `HAVE_SMALL`), and a slow resumable mode driven by `coder->sequence`: `SEQ_NORMALIZE`, `SEQ_IS_MATCH`, `SEQ_LITERAL`, `SEQ_LITERAL_MATCHED`, `SEQ_LITERAL_WRITE`, `SEQ_IS_REP`, `SEQ_MATCH_LEN_CHOICE`, `SEQ_MATCH_LEN_CHOICE2`, `SEQ_MATCH_LEN_BITTREE`, `SEQ_DIST_SLOT`, `SEQ_DIST_MODEL`, `SEQ_DIRECT`, `SEQ_ALIGN`, `SEQ_EOPM`, `SEQ_IS_REP0`, `SEQ_SHORTREP`, `SEQ_IS_REP0_LONG`, `SEQ_IS_REP1`, `SEQ_IS_REP2`, `SEQ_REP_LEN_CHOICE`, `SEQ_REP_LEN_CHOICE2`, `SEQ_REP_LEN_BITTREE`, `SEQ_COPY`.
- Output goes into the dictionary: a literal with `dict_put()`, a match (distance `rep0`, length `len`) with `dict_repeat()`; a failing `dict_repeat()` leads to `LZMA_DATA_ERROR`.
- End handling: the end-of-payload marker (EOPM) is only valid when `eopm_is_valid` (size unknown, or `allow_eopm`). With a known size (always the case for LZMA2 chunks) the decoder stops at the size and requires `rc_is_finished()`. If the size is used up but the decoder still wants to write (`SEQ_LITERAL_WRITE`, `SEQ_SHORTREP`, `SEQ_COPY`) -> `LZMA_DATA_ERROR`. On `LZMA_STREAM_END` it calls `rc_reset()` so the next LZMA2 chunk can start.

## 9. Optional filters between LZMA2 and the Block decoder

- **BCJ ("simple") filters**, `src/liblzma/simple/simple_coder.c`: `simple_code()` gets data from the next coder through `copy_or_code()`, preferably straight into `out`, then runs the architecture function via `call_filter()` (`coder->filter(...)`, files `x86.c`, `arm.c`, `arm64.c`, `riscv.c`, ...). Bytes the filter could not process yet are kept in `coder->buffer` and `*out_pos` is rewound; when the next coder returns `LZMA_STREAM_END` (`end_was_reached`) the rest is passed through unfiltered. `LZMA_SYNC_FLUSH` gives `LZMA_OPTIONS_ERROR`. The per-architecture filter bodies were not read.
- **Delta filter**, `src/liblzma/delta/delta_decoder.c`: `delta_decode()` calls `next.code()` and then `decode_buffer()` adds back the byte at `distance` using a 256-byte `history` ring, in place in the output buffer.

## 10. The way back out

1. LZMA decoder writes into the dictionary (`dict_put` / `dict_repeat`), or LZMA2 `SEQ_COPY` writes via `dict_write`.
2. `decode_buffer()` in `lz_decoder.c` copies from the dictionary to the caller's buffer.
3. BCJ/Delta filters (if any) transform that buffer in place.
4. `block_decode()` counts the bytes, updates the check, later verifies padding and check.
5. `stream_decode()` records the Block sizes, later verifies Index and Footer.
6. `lzma_code()` updates `next_out/avail_out/total_out`.
7. `coder_normal()` calls `coder_write_output()` -> `io_write()` when the buffer is full and at the end; `io_close()` finishes the file pair.
