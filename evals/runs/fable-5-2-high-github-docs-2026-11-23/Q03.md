# Setting up the authenticator app by hand (no QR code)

## The values to type in

If you cannot scan the QR code, enter these parameters in your authenticator (TOTP) app. They are the same values that are encoded in the QR code. (data/reusables/two_fa/manual-totp-app-setup.md, shown in content/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication.md under "Manually configuring a TOTP app")

| Field | Value |
|---|---|
| Type | `TOTP` |
| Label | `GitHub:<username>`, where `<username>` is your GitHub handle, for example `GitHub:monalisa` |
| Secret | The encoded setup key. GitHub shows it when you click "Setup key" during configuration |
| Issuer | `GitHub` |
| Algorithm | SHA1 (the default) |
| Digits | 6 (the default) |
| Period | 30 seconds (the default) |

The only value that is unique to you and secret is the **Secret** (the setup key). Algorithm, Digits and Period are the defaults, so many apps will not ask for them.

## Where to find the setup key

1. In the upper-right corner of any GitHub page, click your profile picture, then click **Settings**. (data/reusables/user-settings/access_settings.md)
2. In the "Access" section of the sidebar, click **Password and authentication**. (data/reusables/user-settings/security.md)
3. In the "Two-factor authentication" section, click **Enable two-factor authentication**. (data/reusables/two_fa/enable-two-factor-authentication.md)
4. Under "Scan the QR code", click **setup key**. GitHub shows a code, the TOTP secret, that you can enter manually in your app instead of scanning. (data/reusables/two_fa/enable-totp-app-method.md)
5. Enter the values from the table above in your app. The app saves your GitHub account and generates a new authentication code every few seconds. On GitHub, type the current six-digit code into the field under "Verify the code from the app." (data/reusables/two_fa/enable-totp-app-method.md)
6. Under "Save your recovery codes", click **Download** and store the codes in a secure place, then click **I have saved my recovery codes**. Only then is two-factor authentication enabled for your account. (data/reusables/two_fa/save_your_recovery_codes_during_2fa_setup.md)

## Good to know

- The setup key is the TOTP secret. If you save it, you can set up the same authentication on more than one device. If two-factor authentication is already enabled and you want to add another device, you must re-configure your TOTP app from your security settings. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication.md)
- The same manual parameters apply when you change your two-factor method later. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/changing-your-two-factor-authentication-method.md)
- The article applies to GitHub Free/Pro/Team, GitHub Enterprise Cloud and GitHub Enterprise Server. (front matter `versions` of content/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication.md)
