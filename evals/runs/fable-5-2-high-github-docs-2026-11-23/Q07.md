# Answer

# Lost phone, no recovery codes, password known

## Short answer

- Yes, there is a way back in if you still have one more proof of identity: a passkey or security key you added earlier, or — through GitHub's account recovery request — a device you have signed in from before, an SSH key, or a personal access token.
- The account recovery request can take up to three business days.
- No, GitHub Support cannot simply switch two-factor authentication off for you.

(The recovery request described below is documented for GitHub.com: GitHub Free/Pro/Team and GitHub Enterprise Cloud. For GitHub Enterprise Server the documentation lists only recovery codes, passkey and security key.)

## Step 1 — Try the quick ways first

Each of these gives you access back immediately:

1. **Passkey.** If you added a passkey, you can use it to regain access automatically. A passkey covers both password and two-factor authentication. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/recovering-your-account-if-you-lose-your-2fa-credentials.md)
2. **Security key.** If you set one up, you can use it as the second factor. (same file)
3. **Backup of your authenticator app.** Many authenticator (TOTP) apps back up your codes to the cloud; you can restore them on a new device. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication-recovery-methods.md; content/authentication/securing-your-account-with-two-factor-authentication-2fa/accessing-github-using-two-factor-authentication.md)
4. **Look once more for the recovery codes.** The default file name is `github-recovery-codes.txt`. Check your downloads folder, password manager, other devices and backups. A code looks like `xxxxx-yyyyy` and can be used only once. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/recovering-your-account-if-you-lose-your-2fa-credentials.md; content/authentication/securing-your-account-with-two-factor-authentication-2fa/troubleshooting-two-factor-authentication-issues.md)

Other methods you set up before (for example GitHub Mobile on another device) can also be used. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/troubleshooting-two-factor-authentication-issues.md)

## Step 2 — Account recovery request (you know your password)

If you know your password but have neither the two-factor credentials nor the recovery codes, you can have a one-time password sent to your verified email address to start verification. You then have to prove your identity with a recovery factor, such as an SSH key or a previously verified device. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/recovering-your-account-if-you-lose-your-2fa-credentials.md, section "Authenticating with a verified device, SSH token, or personal access token")

Steps:

1. Go to `https://github.com/login`. (data/reusables/accounts/prompt-for-2fa-recovery-code.md)
2. Type your username and password and click **Sign in**. This brings up the two-factor prompt. (same file)
3. Under "More options", click **2FA recovery code**. (same file)
4. Under "More options", click **Begin account or email recovery**. (data/reusables/accounts/start-automated-recovery-with-password.md)
5. In the window that appears, click **I understand, get started**. (same file)
6. If asked to verify an email address, click **Send one-time password**. It is sent to your primary and backup email addresses (all verified emails count as backup addresses unless you chose a specific one). (same file)
7. Type the one-time password from the email and click **Verify email address**. (same file)
8. Choose a recovery verification factor (data/reusables/accounts/choose-recovery-verification-factor.md):
   - **Verify with this device** — if you have logged in to this account from the current device before;
   - **SSH key** — if you set up an SSH key on the account before;
   - **Personal access token** — if you set one up before.
9. A member of GitHub Support reviews the request and emails you. If it is approved, you receive a link to complete the recovery. If it is denied, the email includes a way to contact support. (data/reusables/accounts/automated-recovery-review-period-notice.md)

Things to know:

- A factor may not be available for recovery even if you used it before. For example, SSH keys are removed from accounts after a period of inactivity. (data/reusables/accounts/choose-recovery-verification-factor.md)
- So do the request from a computer and browser you have already used with this account, if you can.

## How long it takes

- "For security reasons, regaining access to your account by authenticating with a one-time password can take up to three business days." GitHub will not review additional requests submitted during this time. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/recovering-your-account-if-you-lose-your-2fa-credentials.md)
- GitHub Support reviews the request and emails you within three business days. (data/reusables/accounts/automated-recovery-review-period-notice.md)
- The same article also speaks of a "3-5 day waiting period": if you find your two-factor credentials or recovery codes in the meantime, you can use them at any time during that period. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/recovering-your-account-if-you-lose-your-2fa-credentials.md) The documentation gives both figures and does not explain the difference.

## Can Support switch two-factor authentication off?

No.

- For security reasons, GitHub Support will not be able to restore access to accounts with two-factor authentication enabled if you lose your two-factor credentials or lose access to your recovery methods. (data/reusables/two_fa/support-may-not-help.md)
- You must use the existing account recovery methods. GitHub does not support any other means of recovery, including social or ID verification by GitHub staff; this protects accounts against social engineering. (content/site-policy/other-site-policies/github-account-recovery-policy.md)
- GitHub Support also cannot help with troubleshooting your two-factor methods. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/troubleshooting-two-factor-authentication-issues.md)

Support's only role here is to review the recovery request from Step 2.

## If none of this works

- If you cannot use any recovery method, you have permanently lost access to the account. (data/reusables/two_fa/unlink-email-address.md; content/site-policy/other-site-policies/github-account-recovery-policy.md)
- You can still unlink your email address from the locked account and link it to a new or existing account. This does not disable two-factor authentication and does not give access to the locked account. With your password, the path is the same as steps 1–7 above, then **Start unlinking email**. (content/account-and-profile/how-tos/account-management/unlinking-your-email-address-from-a-locked-account.md; data/reusables/accounts/unlinking-email-address.md)
- You may clone or fork any public content of the lost account; GitHub Support will not recover the contents of a locked account. (content/site-policy/other-site-policies/github-account-recovery-policy.md)
- If the locked account has a payment method, contact Support to have it removed. (content/site-policy/other-site-policies/github-account-recovery-policy.md)

## After you are back in

Download new recovery codes and store them in a password manager, and set up more than one two-factor method. (content/authentication/securing-your-account-with-two-factor-authentication-2fa/configuring-two-factor-authentication-recovery-methods.md)
