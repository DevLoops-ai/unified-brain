I traced the path for a single-threaded `.xz` file run through the `xz` command, from the moment input bytes are read to the moment output is written. Everything below comes from the checkout at `45d08abc`. I did not need git history, so there are no commit citations other than HEAD.

## 0. Frontend: the `xz` program (`src/xz/coder.c`)

- **`coder_run`**
  - Opens the source file with `io_open_src`.
  - When decompressing, it reads the first chunk of input before doing anything else: `io_read(pair, &in_buf, IO_BUFFER_SIZE)`. This chunk is needed to detect the file format.
  - It then calls `coder_init`, opens the output file with `io_open_dest` (skipped for `--test`), and runs `coder_normal`.
  - `IO_BUFFER_SIZE` is defined in `src/xz/file_io.h` as `BUFSIZ & ~7U`, or 8192 on some builds.
- **`coder_init`, building the flags**
  - Adds `LZMA_TELL_UNSUPPORTED_CHECK`, or `LZMA_IGNORE_CHECK` when `--ignore-check` is given.
  - Adds `LZMA_CONCATENATED` unless `--single-stream` is given.
- **`coder_init`, detecting the format**
  - `is_format_xz` compares the 6 magic bytes `FD 37 7A 58 5A 00`.
  - `is_format_lzip` comes next.
  - `is_format_lzma` decodes 5 property bytes with `lzma_properties_decode`.
- **`coder_init`, choosing the decoder**
  - `.xz` uses `lzma_stream_decoder_mt` when `MYTHREAD_ENABLED`, otherwise `lzma_stream_decoder`.
  - `.lzma` uses `lzma_alone_decoder`, `.lz` uses `lzma_lzip_decoder`, and `--format=raw` uses `lzma_raw_decoder`.
  - An unknown format with `-dcf` falls back to `coder_passthru`, which copies the input unchanged.
- **`coder_init`, early header check:** it then calls `lzma_code(LZMA_RUN)` once with no output space. This decodes the headers early, so a memory-limit error or an unsupported check type shows up before the output file is created.
- **`coder_normal`, the main loop**
  - Refill: when `avail_in == 0`, it calls `io_read`, and switches to `LZMA_FINISH` once `src_eof` is reached.
  - Decode: it calls `lzma_code(&strm, action)`.
  - Write: when `avail_out == 0`, `coder_write_output` calls `io_write` and resets `next_out`/`avail_out`.
  - On `LZMA_STREAM_END` it checks for trailing garbage by reading one more byte, unless `allow_trailing_input` is set.
  - `LZMA_UNSUPPORTED_CHECK` is only a warning and decoding continues. Any other non-OK return writes out what was decoded so far, then stops.

## 1. Library entry point (`src/liblzma/common/common.c`)

- **`lzma_code`**
  - Validates the arguments and the `supported_actions` list.
  - Advances the `internal->sequence` state machine: `ISEQ_RUN`, `ISEQ_FINISH`, and so on. Once in `ISEQ_FINISH`, the same action and the same `avail_in` are required on every later call.
  - Calls the top coder: `internal->next.code(coder, allocator, next_in, &in_pos, avail_in, next_out, &out_pos, avail_out, action)`.
  - Afterwards it moves `next_in`/`next_out` forward and updates `total_in`/`total_out`.
  - It returns `LZMA_BUF_ERROR` only on the second call in a row that makes no progress (`allow_buf_error`).
- **How the layers connect:** every layer below is an `lzma_next_coder` with a `.code` function pointer, and each layer calls its child's `.code` itself. `lzma_next_filter_init` is the helper that initializes `filters[0]` into a `next` slot.

## 2. Stream layer (`src/liblzma/common/stream_decoder.c`, `stream_decode`)

This is a resumable state machine.

1. **`SEQ_STREAM_HEADER`**
   - Collects 12 bytes into `coder->buffer` using `lzma_bufcpy`.
   - `lzma_stream_header_decode` (`stream_flags_decoder.c`) checks the magic bytes and the CRC32 of the flags, and extracts the check type.
   - Depending on the flags, it can return `LZMA_NO_CHECK`, `LZMA_UNSUPPORTED_CHECK` or `LZMA_GET_CHECK`. Decoding resumes afterwards at `SEQ_BLOCK_HEADER`.
2. **`SEQ_BLOCK_HEADER`**
   - A first byte of `0x00` (`INDEX_INDICATOR`) means the Index starts here, so it jumps to `SEQ_INDEX`.
   - Otherwise the header size comes from `lzma_block_header_size_decode(in[*in_pos])`, and the whole Block Header is buffered.
3. **`SEQ_BLOCK_INIT`**
   - `lzma_block_header_decode` (`block_header_decoder.c`):
     - verifies the header's CRC32;
     - reads the optional Compressed and Uncompressed Size fields as variable-length integers;
     - reads 1 to 4 Filter Flags entries through `lzma_filter_flags_decode`, which calls `lzma_properties_decode` and then the filter's own `props_decode`. For example, `lzma_lzma2_props_decode` turns its 1 byte into the dictionary size.
   - Memory check: `lzma_raw_decoder_memusage(filters)` is compared to `memlimit`. If it is too high, `LZMA_MEMLIMIT_ERROR` is returned and this step can be retried.
   - `lzma_block_decoder_init` sets up the Block layer. The filter options are then freed.
4. **`SEQ_BLOCK_RUN`**
   - Calls `block_decoder.code` repeatedly.
   - On `LZMA_STREAM_END` it adds `(unpadded_size, uncompressed_size)` to the Index hash with `lzma_index_hash_append`, then goes back to `SEQ_BLOCK_HEADER`.
5. **`SEQ_INDEX`:** `lzma_index_hash_decode` (`index_hash.c`) parses the Index fields:
   - the record count and the size pairs (`SEQ_COUNT`, `SEQ_UNPADDED`, `SEQ_UNCOMPRESSED`);
   - the padding and the CRC32 (`SEQ_PADDING`, `SEQ_CRC32`).

   It hashes these records and compares the result with the hash it built from the Blocks it actually decoded.
6. **`SEQ_STREAM_FOOTER`**
   - `lzma_stream_footer_decode` checks the CRC and reads Backward Size.
   - Backward Size must equal `lzma_index_hash_size`.
   - `lzma_stream_flags_compare` requires the header flags and the footer flags to match.
7. **`SEQ_STREAM_PADDING`** (only when `concatenated` is set)
   - Skips zero bytes, which must come in groups of 4.
   - A non-zero byte means another Stream follows, so it calls `stream_decoder_reset` and starts again at step 1.
   - At end of input with `LZMA_FINISH`, it returns `LZMA_STREAM_END`.

## 3. Block layer (`src/liblzma/common/block_decoder.c`, `block_decode`)

- **`SEQ_CODE`**
  - Limits the input and output windows (`in_stop`, `out_stop`) to `compressed_limit` and `uncompressed_limit`. These come from the header sizes, or from the largest valid value when a size is unknown (`lzma_block_decoder_init`).
  - Calls the filter chain through `coder->next.code`.
  - Counts the bytes consumed and produced, and updates the integrity check over the new output with `lzma_check_update` (`check/check.c`) unless checks are ignored.
  - Inconsistency checks return `LZMA_DATA_ERROR`, for example "both sizes reached but no STREAM_END".
  - On `STREAM_END`, the counted sizes must match the header values.
- **`SEQ_PADDING`:** 0 to 3 zero bytes, so the compressed data ends on a 4-byte boundary.
- **`SEQ_CHECK`:** reads the stored CRC32, CRC64 or SHA-256 value and compares it (`memcmp`) with the result of `lzma_check_finish`.

## 4. Filter chain construction

- `lzma_block_decoder_init` calls `lzma_raw_decoder_init` (`filter_decoder.c`), which calls `lzma_raw_coder_init` (`filter_common.c`).
- `lzma_validate_chain` enforces:
  - 1 to 4 filters;
  - the last filter must be one that can end the chain (`last_ok`);
  - at most 3 filters that change the data size.
- **The decoder keeps the header order of the filters; the encoder reverses it** (the `is_encoder` branch).
- So `filters[0]`, for example the x86 BCJ filter, is the coder that the Block layer calls. That coder pulls data from `filters[1]`, for example LZMA2, which is always last. Data moves upward from LZMA2 through BCJ/Delta to the Block layer.
- Each filter's init function sets up its child with `lzma_next_filter_init(..., filters + 1)` (`lz_decoder.c`, `lzma_lz_decoder_init`).
- The lookup table is `decoders[]` in `filter_decoder.c`: LZMA1, LZMA1EXT, LZMA2, x86, PowerPC, IA64, ARM, ARM-Thumb, ARM64, SPARC, RISC-V and Delta.

## 5. Optional BCJ / Delta filters (applied after LZMA2 has produced data)

- **BCJ filters** (`simple/simple_coder.c`, `simple_code`)
  - `copy_or_code` calls the child, so LZMA2 decodes directly into the caller's `out[]`.
  - `call_filter` then converts branch addresses back in place, for example the x86 version in `simple/x86.c`.
  - Bytes at the end that cannot be converted yet are moved to `coder->buffer` and held until more data arrives.
  - `LZMA_SYNC_FLUSH` is rejected.
- **Delta filter** (`delta/delta_decoder.c`, `delta_decode`): calls the child, then `decode_buffer` adds `history[(distance + pos) & 0xFF]` to each output byte, in place.

## 6. LZ / dictionary layer (`src/liblzma/lz/lz_decoder.c`)

- **`lzma_lz_decoder_init`**
  - Calls the specific `lz_init` function (here `lzma2_decoder_init`), which reports the dictionary size.
  - Raises the size to at least 4096 bytes, rounds it up to a multiple of 16, and allocates `dict_size + 2 * LZ_DICT_REPEAT_MAX` bytes. `LZ_DICT_REPEAT_MAX` is 288 (`lz_decoder.h`).
  - Copies in a preset dictionary if one was given.
- **`lz_decode`:** LZMA/LZMA2 is always the last filter, so it goes straight to `decode_buffer`. There is also a temp-buffer path for a non-last LZ filter, but no current filter uses it.
- **`decode_buffer`, step by step:**
  1. If `dict.pos == dict.size`, it wraps the dictionary: the last 288 bytes are copied to the front and `has_wrapped` is set.
  2. It sets `dict.limit = pos + min(output space left, dictionary space left)`.
  3. It calls `lz.code`, which writes into the dictionary.
  4. It `memcpy`s the newly written range `[dict_start, dict.pos)` into `out[]`.
  5. If `dict.need_reset` was raised, it calls `lz_decoder_reset`.
- **Dictionary primitives** (`lz_decoder.h`):
  - `dict_put` writes one literal byte.
  - `dict_repeat` copies a match: byte by byte when the source and target overlap (distance < length), otherwise with `memcpy`.
  - `dict_is_distance_valid` checks `full > distance`.
  - `dict_write` copies uncompressed chunks.

## 7. LZMA2 chunk layer (`src/liblzma/lzma/lzma2_decoder.c`, `lzma2_decode`)

- **`SEQ_CONTROL`** reads one control byte:
  - `0x00`: end of data, returns `LZMA_STREAM_END`.
  - `0x01`: uncompressed chunk with a dictionary reset. `0x02`: uncompressed chunk without a reset.
  - `0x80` and above: LZMA chunk. The low 5 bits hold the top bits of the uncompressed size.
  - `0xA0` and above: also reset the LZMA state (`lzma.reset`).
  - `0xC0` and above: also read a new properties byte.
  - `0xE0` and above: also reset the dictionary (`dict_reset`).
  - It returns `DATA_ERROR` if a required dictionary reset or properties byte is missing.
- **Size fields:** `SEQ_UNCOMPRESSED_1/2` and `SEQ_COMPRESSED_0/1` read the 16-bit sizes, each stored as the value minus 1. Then `lzma.set_uncompressed(size, false)` sets the expected output size with no end marker allowed.
- **`SEQ_PROPERTIES`:** `lzma_lzma_lclppb_decode` reads the lc/lp/pb byte, then `lzma_decoder_reset` runs.
- **`SEQ_LZMA`:** calls `lzma_decode`, which writes into the dictionary. Input used must stay within `compressed_size`, and the chunk must be fully consumed when it returns STREAM_END.
- **`SEQ_COPY`:** `dict_write` copies an uncompressed chunk as is.

## 8. LZMA core and range decoder (`src/liblzma/lzma/lzma_decoder.c`, `lzma_decode`; `src/liblzma/rangecoder/range_decoder.h`)

- **`rc_read_init`:** each chunk starts by reading 5 bytes into `rc.code`. The first byte must be `0x00`.
- **Working copies:** `rc_to_local` and local copies of the state, `rep0`–`rep3` and the dictionary are used inside the loop.
- **Output limit:** if the expected uncompressed size fits in the space left, `dict.limit` is clamped to it and `might_finish_without_eopm` is set.
- **Two loop modes:**
  - Fast mode (not built with `HAVE_SMALL`): used while `rc_is_fast_allowed()`, meaning at least `LZMA_IN_REQUIRED` (20) input bytes are left.
  - Resumable mode (the `case SEQ_*` labels): saves `coder->sequence` so a later call can continue mid-symbol.
- **Decoding each symbol**, starting with the bit `is_match[state][pos_state]`:
  - **Literal:** `literal_subcoder` picks the probability table from the lc/lp context. It decodes 8 bits with `rc_bittree8`, or with `rc_matched_literal` against `dict_get(rep0)` right after a match. The byte goes out with `dict_put`.
  - **Match** (`is_rep = 0`): shifts the rep distances, decodes the length (`len_decode_fast`), then the 6-bit distance slot. Small distances come from `pos_special` (reverse bittree). Large ones use `rc_direct` bits plus 4 aligned bits (`rc_bittree_rev4`). A distance of `UINT32_MAX` is the end-of-payload marker (`eopm:`/`SEQ_EOPM`). Otherwise `dict_is_distance_valid` is checked.
  - **Repeat match:** `is_rep0`, `is_rep0_long`, `is_rep1` and `is_rep2` select a short rep (1 byte) or one of rep0–rep3, then `rep_len_decoder` gives the length.
  - **Copying:** `dict_repeat(&dict, rep0, &len)` copies the match. If the output limit is hit mid-copy, it saves `SEQ_COPY`.
- **End of chunk** (`SEQ_IS_MATCH` when `dict.pos == dict.limit` and the size is known): `rc_is_finished` (`code == 0`) gives STREAM_END. Otherwise an end marker is allowed only if `allow_eopm` is set.
- **On exit (`out:`):** saves the state, reduces `uncompressed_size` by the bytes produced, and calls `rc_reset` on STREAM_END so the next LZMA2 chunk can start.

## 9. Multithreaded variant (what `xz` actually uses when threads are enabled)

- **`stream_decode_mt`** (`stream_decoder_mt.c`) has the same stream sequence, plus two block paths:
  - `SEQ_BLOCK_THR_*`: each Block goes to a worker thread (`worker_decoder`) that runs its own `block_decoder.code` in 16 KiB input pieces. Output is collected in order through `lzma_outq_*` / `read_output_and_wait`.
  - `SEQ_BLOCK_DIRECT_*`: single-threaded fallback.
- **Direct mode is used when** either size is missing from the Block Header (`is_direct_mode_needed`), or when one Block's memory need exceeds `memlimit_threading`.
- `coder_init` sets `memlimit_threading = 0` when there is 1 thread, which forces direct mode.
- In threaded mode, the Index hash entry is added up front from the header sizes; the Block decoder verifies them while decoding.
