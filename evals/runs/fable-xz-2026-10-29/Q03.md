# xz / liblzma decompression path (commit 45d08abc)

Everything below is from the checkout; file paths are relative to `src/`. I walk the default single-threaded `.xz` path first, then note where the threaded decoder and the CLI differ.

## 0. Architecture in one paragraph

liblzma is a chain of "next coders". Each stage is a `lzma_next_coder` struct holding `coder` (private state), `code` (a function with the uniform signature `in/in_pos/in_size, out/out_pos/out_size, action`), `end`, and optional `get_check`/`memconfig` (`liblzma/common/common.h`, `struct lzma_next_coder_s`, `lzma_code_function`). A stage pulls from the stage below it by calling `next.code(...)`. Decompression is therefore: **Stream decoder → Block decoder → raw filter chain (0–3 non-LZ filters → LZ wrapper → LZMA2 → LZMA1 → range decoder)**, with the output flowing back up through the same calls.

## 1. Entry: `lzma_stream_decoder()` and `lzma_code()`

- `lzma_stream_decoder(strm, memlimit, flags)` (`liblzma/common/stream_decoder.c`) runs the `lzma_next_strm_init` macro (`common.h`), which calls `lzma_strm_init()` (allocates `strm->internal`, `common.c`) and then `lzma_stream_decoder_init()`. That sets `next->code = &stream_decode`, `next->get_check`, `next->memconfig`, stores `memlimit`/flag booleans (`tell_no_check`, `ignore_check`, `concatenated`, ...) and calls `stream_decoder_reset()` which allocates the `lzma_index_hash` and sets `sequence = SEQ_STREAM_HEADER`.
- Every application call goes through `lzma_code(strm, action)` (`common.c`). It validates arguments and the `ISEQ_*` state machine, calls `strm->internal->next.code(...)` with local `in_pos`/`out_pos`, then advances `next_in/avail_in/total_in` and `next_out/avail_out/total_out`. It also converts the second consecutive no-progress `LZMA_OK` into `LZMA_BUF_ERROR` (the `allow_buf_error` flag), maps `LZMA_TIMED_OUT` to `LZMA_OK`, and marks fatal errors with `ISEQ_ERROR`.

## 2. Stream layer: `stream_decode()` (`liblzma/common/stream_decoder.c`)

A `while(true) switch(coder->sequence)` state machine:

1. **`SEQ_STREAM_HEADER`** — `lzma_bufcpy()` collects 12 bytes into `coder->buffer`, then `lzma_stream_header_decode()` (`stream_flags_decoder.c`) checks the magic (`LZMA_FORMAT_ERROR` on mismatch), verifies the CRC32 over the Stream Flags, and decodes the check type via `stream_flags_decode()`. The check type is copied into `coder->block_options.check`. Optional early returns `LZMA_NO_CHECK` / `LZMA_UNSUPPORTED_CHECK` / `LZMA_GET_CHECK` happen here.
2. **`SEQ_BLOCK_HEADER`** — peeks the first byte: if it is `INDEX_INDICATOR` (0x00) it jumps to `SEQ_INDEX`; otherwise `lzma_block_header_size_decode()` gives the header size and the whole header is buffered.
3. **`SEQ_BLOCK_INIT`** — `lzma_block_header_decode()` (`block_header_decoder.c`): verifies CRC32, reads flags, optional Compressed/Uncompressed Size via `lzma_vli_decode()`, then 1–4 Filter Flags via `lzma_filter_flags_decode()` (`filter_flags_decoder.c`), which decodes Filter ID + props size and calls `lzma_properties_decode()` (`filter_decoder.c`) → the per-filter `props_decode` (e.g. `lzma_lzma2_props_decode` turns the 1-byte dictionary-size code into `lzma_options_lzma.dict_size`). Then `lzma_raw_decoder_memusage()` is compared to `coder->memlimit` (`LZMA_MEMLIMIT_ERROR` if too big; this is a separate sequence point so the application can raise the limit and retry), and `lzma_block_decoder_init()` builds the Block decoder. Filter options are freed immediately after.
4. **`SEQ_BLOCK_RUN`** — calls `coder->block_decoder.code(...)` with the caller's in/out buffers directly. On `LZMA_STREAM_END` it records the block in the Index hash: `lzma_index_hash_append(index_hash, lzma_block_unpadded_size(&block_options), block_options.uncompressed_size)`, then loops back to `SEQ_BLOCK_HEADER`.
5. **`SEQ_INDEX`** — `lzma_index_hash_decode()` (`index_hash.c`) parses the Index (record count, Unpadded Size / Uncompressed Size pairs, padding, CRC32) and compares both the sums and a `LZMA_CHECK_BEST` hash of the record pairs against what was accumulated from the actual Blocks (`hash_append()` on both sides; mismatch → `LZMA_DATA_ERROR`).
6. **`SEQ_STREAM_FOOTER`** — `lzma_stream_footer_decode()` (`stream_flags_decoder.c`): CRC32, footer magic, Backward Size. Then `lzma_index_hash_size()` must equal `backward_size`, and `lzma_stream_flags_compare()` must match header and footer flags. Without `LZMA_CONCATENATED` this returns `LZMA_STREAM_END`.
7. **`SEQ_STREAM_PADDING`** (concatenated mode only) — skips zero bytes, requires a multiple of 4, and on a non-zero byte calls `stream_decoder_reset()` to start the next Stream. `LZMA_STREAM_END` is only returned when `action == LZMA_FINISH` and padding is aligned.

## 3. Block layer: `block_decode()` (`liblzma/common/block_decoder.c`)

`lzma_block_decoder_init()` computes `compressed_limit`/`uncompressed_limit` from the header sizes (or the VLI maxima when unknown), calls `lzma_check_init()`, and initializes the filter chain with `lzma_raw_decoder_init(&coder->next, allocator, block->filters)`.

- **`SEQ_CODE`** — clamps `in_stop`/`out_stop` to the remaining limits, calls `coder->next.code(...)` (top of the filter chain), accumulates `compressed_size`/`uncompressed_size`, and runs the consistency checks (sizes reached but no `LZMA_STREAM_END`, etc. → `LZMA_DATA_ERROR`). It feeds the *newly produced output bytes* to `lzma_check_update(&coder->check, block->check, out + out_start, out_used)` unless `ignore_check`. On `LZMA_STREAM_END` it validates sizes against the header (`is_size_valid()`) and writes the final sizes back into `coder->block` (this is what the Stream layer later hashes).
- **`SEQ_PADDING`** — consumes zero bytes until `compressed_size` is a multiple of 4; then `lzma_check_finish()`.
- **`SEQ_CHECK`** — copies `lzma_check_size()` bytes into `block->raw_check` and `memcmp`s against `coder->check.buffer.u8` (`LZMA_DATA_ERROR` on mismatch; skipped if the check type is unsupported by this build). Returns `LZMA_STREAM_END`.

The check implementations are dispatched in `liblzma/check/check.c` (`lzma_check_init/update/finish`: CRC32, CRC64, SHA-256).

## 4. Filter chain construction: `lzma_raw_decoder_init()` → `lzma_raw_coder_init()`

`lzma_raw_decoder_init()` (`filter_decoder.c`) calls `lzma_raw_coder_init(next, allocator, options, &coder_find, false)` (`filter_common.c`). That function:
- `lzma_validate_chain()` enforces 1–4 filters, at most 3 size-changing filters, and that the last filter is one allowed last (`last_ok`, i.e. LZMA1/LZMA2).
- For the decoder the filters are kept in on-disk order (encoder reverses them). It fills `lzma_filter_info[]` with each filter's `init` from the `decoders[]` table in `filter_decoder.c` (`LZMA_FILTER_LZMA2 → lzma_lzma2_decoder_init`, `LZMA_FILTER_X86 → lzma_simple_x86_decoder_init`, `LZMA_FILTER_DELTA → lzma_delta_decoder_init`, ...).
- `lzma_next_filter_init(next, allocator, filters)` (`common.c`) calls `filters[0].init(...)`; each filter's init calls `lzma_next_filter_init(&coder->next, allocator, filters + 1)` for the one below it, so the chain is built recursively.

Data flow: filter N's `code()` first calls filter N+1's `code()` to get *its* output into N's out buffer (or a temp buffer), then transforms it in place. So in a BCJ+LZMA2 chain, LZMA2 decodes first and the BCJ filter post-processes.

### 4a. Non-LZ filters (optional, 0–3 of them)
- **BCJ/"simple" filters** — `simple_code()` (`liblzma/simple/simple_coder.c`): calls `copy_or_code()` (which calls `coder->next.code()`), then `call_filter()` runs the arch function (e.g. `x86_code()` in `simple/x86.c`) in place over `out[]`, keeping unfiltered tail bytes in `coder->buffer[]` for the next round. `simple_code()` rejects `LZMA_SYNC_FLUSH`.
- **Delta** — `delta_decode()` (`liblzma/delta/delta_decoder.c`): calls `coder->next.code()`, then `decode_buffer()` adds back the byte at `distance` from a 256-byte `history[]` ring.

### 4b. LZ wrapper: `lz_decode()` / `decode_buffer()` (`liblzma/lz/lz_decoder.c`)
`lzma_lz_decoder_init()` allocates the dictionary (`dict_size` rounded to ≥4096 and multiple of 16, plus `2 * LZ_DICT_REPEAT_MAX` = 576 extra bytes, `lz_decoder.h`), applies a preset dictionary if any, sets `next->code = &lz_decode`, and inits the next filter (normally none: LZMA/LZMA2 must be last, asserted in `lzma_lzma2_decoder_init`).

`decode_buffer()`: wraps `dict.pos` when it hits `dict.size` (copying the last 288 bytes to the front so `dict_repeat()` never has to split a copy), sets `dict.limit = pos + min(out space, dict space)`, calls `coder->lz.code(coder->lz.coder, &coder->dict, in, in_pos, in_size)` (LZMA2 or LZMA1), then **memcpy's the newly written dictionary range into `out[]`** — this is where output bytes materialize. Handles `dict.need_reset` by `lz_decoder_reset()`.

`lz_decode()` either calls `decode_buffer()` directly (last in chain) or, if there is a next filter, pulls via `coder->next.code()` into `temp.buffer` first (this branch is for a hypothetical future filter below LZ; today LZMA is always last).

### 4c. LZMA2 chunk layer: `lzma2_decode()` (`liblzma/lzma/lzma2_decoder.c`)
State machine on the control byte: `0x00` → `LZMA_STREAM_END`; `>= 0xE0` or `== 1` → dictionary reset (`dict_reset()`, return so the LZ layer flushes); `>= 0x80` LZMA chunk with 5+16 bits of uncompressed size (`SEQ_UNCOMPRESSED_1/2`), 16 bits compressed size (`SEQ_COMPRESSED_0/1`), optional `SEQ_PROPERTIES` (`lzma_lzma_lclppb_decode()` then `coder->lzma.reset()`), state reset for `>= 0xA0`; `1`/`2` → uncompressed chunk copied with `dict_write()` in `SEQ_COPY`. In `SEQ_LZMA` it calls `coder->lzma.code(...)` (= `lzma_decode`) and verifies the chunk consumed exactly `compressed_size` bytes.

### 4d. LZMA1 symbol decoder: `lzma_decode()` (`liblzma/lzma/lzma_decoder.c`)
- `rc_read_init()` (`rangecoder/range_decoder.h`) reads the 5 init bytes (first must be 0x00).
- `rc_to_local()` copies the range decoder into locals; the main loop uses `rc_if_0`/`rc_update_0`/`rc_update_1`/`rc_normalize` to decode bits against adaptive `probability` arrays (`is_match`, `is_rep*`, `dist_slot`, `pos_special`, `pos_align`, literal coders, `match_len_decoder`, `rep_len_decoder`).
- Two modes: a fast non-resumable loop used while `rc_is_fast_allowed()` (≥ `LZMA_IN_REQUIRED` = 20 input bytes left) and the dictionary is not at `dict.limit`; and a resumable "slow" loop with `case SEQ_*` labels so it can stop mid-symbol when input runs out (`rc_normalize_safe` sets `coder->sequence` and `goto out`).
- Per symbol: literal (`rc_bittree8` or `rc_matched_literal`, then `dict_put()`), match (length via `len_decode_fast`, distance via `dist_slot` → `pos_special` reverse bittree or `rc_direct` + `rc_bittree_rev4`), or rep match (rep0..rep3 shuffling, short-rep via `dict_put(dict_get(rep0))`). Distances are validated with `dict_is_distance_valid()` (`dict->full > distance`). Copies are done by `dict_repeat()` (`lz_decoder.h`): byte loop when `distance < len`, `memcpy` otherwise; if the copy hits `dict.limit` it saves `SEQ_COPY` and resumes next call.
- End of payload marker is `rep0 == UINT32_MAX`; known-size chunks end when `dict.pos == dict.limit` and `rc_is_finished()` (`code == 0`). On `LZMA_STREAM_END` it `rc_reset()`s for the next LZMA2 chunk.
- `out:` writes `dict.pos/full` back to the caller's `lzma_dict`, which is what `decode_buffer()` then copies to `out[]`.

## 5. Threaded variant (`liblzma/common/stream_decoder_mt.c`)

`lzma_stream_decoder_mt()` installs `stream_decode_mt`. It parses Stream Header / Block Header itself (`decode_block_header()`, calling the same `lzma_block_header_decode`), computes `mem_next_filters` via `lzma_raw_decoder_memusage`, and in `SEQ_BLOCK_INIT` decides per Block: if sizes are unknown (`is_direct_mode_needed()`) or the memory for buffers + filters exceeds `memlimit_threading`, it falls to `SEQ_BLOCK_DIRECT_INIT` and runs the same `lzma_block_decoder_init` + `coder->block_decoder.code(...)` inline; otherwise it appends to the Index hash up front, preallocates an output-queue buffer (`lzma_outq_prealloc_buf`), gets a worker (`get_thread`), inits that worker's `block_decoder`, and the worker thread `worker_decoder()` feeds its private input buffer to `thr->block_decoder.code(...)` in 16 KiB chunks into `thr->outbuf`. The main thread hands finished/partial output to the application in `read_output_and_wait()` via `lzma_outq_read()`. Index/Footer handling (`lzma_index_hash_decode`, `lzma_stream_footer_decode`) is the same as the single-threaded decoder.

## 6. CLI wrapper (`xz/coder.c`)

`coder_init()` sniffs the format (`is_format_xz()` etc.) and picks `lzma_stream_decoder_mt()` (or `lzma_stream_decoder()` without threads), `lzma_alone_decoder()` for `.lzma`, `lzma_lzip_decoder()` for `.lz`, or `lzma_raw_decoder()` for `--format=raw`; it then runs `lzma_code(&strm, LZMA_RUN)` once with `avail_out = 0` to surface header errors / unsupported-check warnings early. `coder_normal()` is the pump: `io_read()` fills `in_buf`, `lzma_code(&strm, action)` with `action` switching to `LZMA_FINISH` at EOF, and `coder_write_output()` → `io_write()` whenever `avail_out == 0`.
