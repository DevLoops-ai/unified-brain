## The change

The first retrieval change made from this eval. In `_candidates`, the
places that mention a reached body's *file name* (its "upward" links: the
build file that compiles it, a checker that lists it, a test that uses it)
were already found by the chains, but went through the hit triage like
every other mention, and the triage — shown three lines of a build file —
dropped them (Q1 cheap run: 2 triage calls, 2 judged, 0 accepted). Change:
those places skip the triage and go straight to the full Jev judgement.
Two narrowings from the Q3 log: not the file's own whole-file body (every
xz source names itself in its header comment: 20 of 109 reverse reads),
and not the includers of a header (`#include` lines: 40 reads, 1 accept).
Everything else — names Jev chose, names next to the link, symbol
mentions — is triaged as before. Cheap configuration otherwise
(`JEV_HIT_TRIAGE=1`, `JEV_NAMES_AS_CHOICE=1`), one run per question.
