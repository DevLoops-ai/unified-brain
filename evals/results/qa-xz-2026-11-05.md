## The change

Five edits in `codebase_qa_service.py`; the first two are the change, the
other three are defaults catching up with `.env`.

1. **Retry near a cut, keep the permissive answer** (`JEV_RETRY_BAND`,
   default 0.10; 0 disables). A judgement that lands on the strict side of
   a cut but within the band is asked once more, and the more permissive
   answer is kept: a place the hit triage dropped at 0.40–0.49 is kept if
   either call keeps it; a chain verdict "reject" at 0.75–0.85 takes the
   call with the lower reject (so it may settle to "continue"); a
   `derived` at 0.65–0.75 takes the lower value; the final second look
   does the same for its reject. The verdict argmax and the names
   question are not retried. Reason: the noise measured on 2026-11-02;
   every flip seen there dropped a true positive. Log marks: `🔁 triage
   retry` lines, ` retry: reject 0.77→0.74 derived 0.13→0.15` on expand
   lines, ` retry: …` on final lines; the evidence record's "read" and
   "second_look" decisions carry a `retry` field.
2. **Files reached by name** (`_file_places`). When Jev chooses a name
   that is a file's basename or stem (`test_compress`, `crc32_x86`), the
   whole-file body of that file is offered as a candidate before the
   mention hits, with the reason "it is the file named `X`, which the
   judge chose to follow". Written in another session for the case where
   a script is talked about everywhere but never reached itself.
   Current state only; a stem used by more than `JEV_EXPAND_MAX_HITS`
   files returns nothing. Known gaps, found in this run's log: its
   candidates do not match the triage grouping (`it mentions …`), so they
   are never triaged; and the dedup against seeds missed (see Q1).
3. `JEV_TRIAGE_FROM` (default 2): groups of fewer places than this skip
   the triage and are read in full. 2 is the behaviour so far; the
   aborted runs above are what a high value does.
4. `JEV_DERIVED_MIN` code default 0.5 → 0.65 (`env.example` already said
   0.65; a fresh install was running 0.5).
5. `JEV_EXPAND_MAX_ADD` code default 60 → 200, with the run-b Q4 numbers
   as the `env.example` comment (open since b).

## Notes for the next runs

  13 % cost for 0 points; the near-ties here were marginal bodies. It is
  insurance for a noisier judge (the open-weights runs) and the log marks
  make its effect countable, so it stays in the code. Whether the default
  stays 0.10 or goes to 0 is a decision for after the open-weights
  numbers, not before.
- **Files by name:** two fixes before it runs again — dedup against the
  seeds by `(file, symbol)`, and route its candidates through the triage
  (phrase the reason as "it mentions `X`" or widen the grouping regex to
  `it (?:mentions|is the file named)`). A body over `JEV_BODY_MAX_CHARS`
  reached by name has no anchor line and Jev sees its head; for those,
  skip the file-name reach and let the mention path find the lines.
- **`license-check.sh`** needs a different idea than a judge change: the
  body is a "continue" at 0.56–0.60 in every run since c, and the

  writer the lead's own excerpt instead of a one-line trail — both
