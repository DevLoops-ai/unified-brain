# xz — question answering, runs to 2026-10-29

Setup: unified-brain service on the author's laptop, database = xz commits
`f7fa309e`..`45d08abc` (1,349 commits), configuration = Part 1 of
`env.example` (Jev `typesafe/jev-1.13`, Qwen3 vectors), writer DeepSeek
V4.1 Flash on Fireworks. This is the cheap configuration: `JEV_HIT_TRIAGE=1`
and `JEV_NAMES_AS_CHOICE=1`, which cut Jev calls by 3–8× compared with the
earlier build (see the "earlier runs" table for what that build cost).
Questions and answer keys: `evals/questions/xz.md` — nine questions, 74
reference points. A tenth question (Block Header sizes vs. decoded bytes)
was removed from the set after the runs: in both configurations the writer
reported that the two functions the key turns on (`is_size_valid()`,
`lzma_block_decoder_init()`) were not in the evidence it was given, and
whether the ingester indexed them has not been checked. The answers to it
are kept in `evals/runs/` but are not scored.

Grading: reference points hit. The keys were written before the runs from
the source at `45d08abc`, and every point was checked against that source
again at grading time. Keys and grading were done by Claude Fable 5.1 (high
reasoning) with direct read access to the checkout, working with the author.
The same model built the system, so this is not an independent grader.

Costs: Jev from `usage.cost` as printed in the answer footer; writer from
the footer's token counts at Fireworks list price, $0.22 / M input and
$0.66 / M output (not invoice-reconciled). Time is wall-clock, question
submitted to answer complete, from the footer.

- Cost, with prompt caching on and at list prices: Opus $0.76 per question,
  Fable $1.95, unified-brain $0.076 — 10× and 26×. Caching is doing most of

## What this does not show

- One or two runs per question; one grader; keys written by the same party
  that built the system.
- Questions only. No modification task was run (fix + test); the only
  public number for that shape of task is jevgrep's 25.8 % saving on ten
  SWE-bench tasks, which is a different measurement.
- The Opus and Fable dollar figures are list price × API usage fields,
  with prompt caching on; a Cursor or Claude Code subscription would bill
  differently. No Cursor run on these nine questions.
